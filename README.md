# Course Registration & Learning Portal 🚀

A multi-page static website designed for student course enrollment and learning resources. Built using semantic HTML5, table-based layouts, and embedded media.

---

## 📌 Pages & Features

### 1. Home / Overview (`tab.html`)
- **Academy Branding:** Introduction header and mission statement.
- **Embedded Media:** Embedded YouTube video tutorial on full-stack development.
- **Curriculum Breakdown:** Structured overview of Frontend, Backend, and Database technologies.
- **Tech Stack Table:** Detailed comparison of core web development tools and platforms.

### 2. Registration Form (`regis.html`)
- **Student Details:** Name, Age, Gender selection (radio buttons), and Email inputs.
- **Course Selection:** Dropdown menu covering SQL, Full Stack, Java, and Python.
- **File Upload:** Direct resume/document upload field.
- **Form Controls:** Reset and Submit buttons.
- **Footer Navigation:** Interlinked navigation between pages and external social channels.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure, forms, tables, frames, and multimedia embeds.
